# Release notes

## v0.1.0

First public release of Linux Computer Use, a local MCP bridge for Codex on Hyprland.

- Isolated window, monitor, and desktop screenshots.
- Native Wayland mouse and keyboard input, monitor discovery, window controls, and application launch.
- Time-limited operator grants, visible access indicator, emergency stop, per-action approval, and redacted audit records.
- Optional AT-SPI inspection and separately approved clipboard access.
- Codex subscription usage reporting and private checkpoints.

Verified on Arch Linux x86-64 with Hyprland 0.57.2. The project includes isolated desktop, permission, and MCP tests. See [verification](docs/verification.md) for coverage and [README](README.md) for setup and limits.
